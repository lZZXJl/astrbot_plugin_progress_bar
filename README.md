# 进度条

办事的时候把进度打进日志，面板的日志窗口里能看着它一格一格走。

不是通知栏——这套东西跑在容器里，碰不到系统的通知服务。
能做的只有往日志里写，窗口开着就看得见。

## 长什么样

彩虹铺色是默认：

```
[进度] 🟥🟥🟧🟧⬜⬜⬜⬜  45%  00:12  下载洛雪
[进度] 🟥🟥🟧🟧🟨🟨🟩🟩 100%  下载洛雪  | 用时 00:50
```

走多少铺多少，没走的那截是白的。宽度加到十二，颜色跟着变成六色各两格。

一行一条，往下滚，不原地刷新。控制台那套 `\r` 在面板里不管用。

## 两条路

**给模型用的工具**：`report_progress(percent, note, status)`

- `percent`：0 到 100
- `note`：一句话，短，别超过十个字
- `status`：`running` 或 `done`

模型办长活时自己调，不用人催。

**手动**：`/进度 45 下载中`

不带参数回一句提示；头一个不是数字，回一句“头一个得是数字”。

## 配置

| 项 | 默认 | 说明 |
|---|---|---|
| `enable_llm_tool` | true | 关掉后工具调用被拒，只剩手动指令 |
| `bar_width` | 8 | 格数。emoji 一格占两个字符宽，别设太大 |
| `min_interval` | 1 | 同一会话两次上报的最小间隔（秒），防刷屏 |
| `prefix` | `[进度]` | 日志行前缀，方便筛 |
| `color_mode` | `rainbow` | 见下 |
| `color_filled` | `🟦` | 只在 `emoji` 模式用 |
| `color_empty` | `⬜` | 没走那截的方块，彩虹模式也用它 |
| `color_code` | `38;5;39` | 只在 `ansi` 模式用 |

### color_mode 四档

- `rainbow`：彩虹铺色，红橙黄绿蓝紫，按宽度均分。默认。
- `emoji`：单色方块，颜色由 `color_filled` 定。🟥🟧🟨🟩🟪🟫⬛ 都收。
- `ansi`：转义码上色，二百五十六色随你填。**日志窗口要认转义码才显色**，不认就是白的。
- `none`：纯字符 `█░`，最稳。

## 改配置时踩过的坑

`_conf_schema.json` 里的 `default` 只在**第一次**建配置文件时生效。
配置文件已经有了，改 schema 不会覆盖它——实际读的是
`data/config/astrbot_plugin_progress_bar_config.json`。

所以：改默认值要连那个 json 一起改，或者直接在面板里改，然后重载。

## 已知的边界

- 不碰任何既有插件，只往日志写。
- 同一会话的计时在进程内，重启就没了。
- 百分比没变的重复上报会被跳过，不会刷屏。
- 卡住等下载的时候不报，等真动了再报——那条进度才是真的。
